# 讨论

需求：

* **做个系统**：干部的廉贞档案/个人事项职能化分析  
  e.g. 有100份档案，包括人事调动、安排等各种信息。如果人来看可以看到各种结构化数据，但不希望只做到单独的检索，  
  还希望能通过人工智能的方式来分析这100份档案中有什么关系（人际关系、亲属、异常行为（异常资金流向）），以可视化形式展现出来。

---

* 需要建模/可视化/应用开发能力  
  比如把 DeepSeek 的回答（纯文本，结构化文档），用 PDF 展现。
  故需要 Python / C++ 的业务能力
* 大数据和业务知识要求并不是很高。  
* 有技术团队，大模型技术开发部署由他们做，我们来构想怎么落地、结构、要不要建系统上的争论。
