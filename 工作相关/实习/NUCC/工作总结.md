# 工作总结

针对 AI + 纪检项目，做了如下主要工作：

1. 前期的需求调研和设计：对项目分析提取了出三类需求：1) 浅层的筛选检索、2) 中层的结构分析、3) 深层的关联分析
2. 调查了解了相关可用技术路线，如 n8n, Dify, LangChain，拥有基本认识和理解
3. 了解了一个 AI 对话应用项目的完整框架和技术栈，大模型端可使用 MindIE 等推理引擎部署大模型推理服务、提供符合 OpenAI 标准的推理 API；后端可通过 FastAPI 提供接口、OpenAI 库调用大模型服务、管理上下文、搭建 AI 应用服务；前端可通过 Ant Design, Ant Design X 等 UI 框架搭建界面、通过网络请求调用后端提供的 AI 应用服务、渲染 AI 服务的回复消息。
4. 了解学习 OpenAI 库相关知识，包括流式响应消息实现方式（返回 StreamingResponse，函数内部通过 yield 返回）、上下文 messages 管理方式、三种 role 的 prompt 区别、tool_calls 的使用方式和最佳实践（tool_calls 可以为大模型提供确定性的服务工具）等
5. 优化现有后端的代码架构，模块化组织，将不同 Agent 通过 gpt_config 注册组织
6. 利用 unified 管线和相关插件（remark, rehype）以及 html-docx 插件，为前端项目添加“模型回复导出”功能
7. ⭐在重构 UI 的新前端项目中，完成了对 AI 对话功能组建的开发。包括：
   * 利用 v0.dev, Cursor 等工具快速完成新项目原型界面设计
   * 采用 React + Vite + TypeScript 技术栈，基于 Ant Design 设计语言进行组件开发
   * 使用 Ant Design X AI 交互框架搭建主要组件，包括：欢迎页、示例问题、对话记录、消息操作按钮、对话框等；并基于该框架的最佳实践实现业务逻辑，包括定义 roles、actions、使用 XRequest 构建自定义请求， useXAgent 管理 Agent 调度， useXChat 管理对话数据
   * 抽象出与后端对接的 Service 层，封装了一个简易的 API Client 对接后端提供的结构，并使用 React-Query 实现从后端获取 Agents 信息并进行服务器数据状态管理。
   * 对大模型流式返回的消息进行解析和渲染，包括对 `<think>` 标签渲染成思维链的处理，判断大模型推理所处状态等
   * 学习并使用 useMemo, useCallback 等进行性能优化，开发的组件库高度模块化，具有可扩展可复用性，能直接对接大模型端已提供的 4 种 Agent
8. 对新上线的项目应用持续优化迭代，代码模块化重构，删除冗余代码，修复问题和缺陷，实现变更需求
9. 参与 AI 纪检项目进行项目演示和介绍视频的剪辑和制作
