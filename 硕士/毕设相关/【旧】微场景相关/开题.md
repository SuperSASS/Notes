# 基于场景的测试

* 纯软件方向
  * 场景通常定义：测试场景(Testing Scenario)代表应用程序中的一个**特定功能或任务**,它从最终**用户的角度**封装了一个**完整且自洽的业务逻辑**。  
    要素：用户目标（What） + 操作序列（How） + 预期结果  
    根据实际运用，有很多不同表示方法：最常见的是自然语言（目标+操作（包含验证）+结果），也有 UML/形式化【引用自Generating Test Scenarios from NL Requirements using Retrieval-Augmented LLMs: An Industrial Study，"Based on project requirements and the development environment"】
    > 与测试用例的区别：
    >
    > 测试用例是开发角度、技术导向的、代码 → 测试用例 → 执行，  
    > 测试场景则是用户角度、业务导向的、用户需求 → 测试场景 → 测试用例 → 执行。
    >
    > 在部分论文中，相当于声明式与命令式的区别，其中测试场景只输入用户目标（预期结果由方法自行判断），操作序列由方法生成。
    > * 测试场景是声明式的，告诉要做什么（What），是粗粒度、高层次的，比如“用户登录”；  
    >   测试场景 = 用户目标
    > * 测试用例是命令式的，除了做什么还要说怎么做（How），还包括细粒度、具体的步骤，比如“用户登录：1. 点击；2. 输入……”  
    >   测试用例 = 用户目标 + 操作步骤 + 预期结果

## 一、前沿研究方向

### 1. **基于大语言模型(LLM)的场景生成** 

这是当前最热门的研究方向,具有很高的创新性和实用价值。

**关键工作:**
使用大语言模型将操作设计域(ODD)的详细描述转换为可执行的仿真场景,结合模型驱动和数据驱动技术,应用提示工程生成与CARLA兼容的ScenarioRunner脚本。

OmniTester系统是一个多模态LLM驱动的测试场景生成工具,采用检索增强生成(RAG)和自我改进机制来增强LLM对场景的理解,从而提高生成更真实场景的能力。

LLM-attacker框架利用大语言模型设计多个LLM代理来识别最优攻击者,优化攻击者的轨迹以生成对抗性场景,这些场景基于自动驾驶系统的性能迭代改进,形成反馈循环。

**研究机会:**
- LLM生成场景的可控性与真实性平衡
- 多模态LLM在复杂交通场景中的应用
- 基于LLM的场景变异与演化策略
- LLM幻觉问题在场景生成中的解决方案

### 2. **组合测试(Combinatorial Testing)驱动的场景生成** 

提出基于组合测试和贝叶斯网络的测试场景生成方法,通过调整权重和目标参数生成不同概率的测试用例,以满足不同需求的测试任务。

基于组合测试的多船遭遇场景生成框架,采用N-wise覆盖策略涵盖所有可能的初始场景状态组合,并引入时空复杂度来过滤过于简单或极度危险的场景。

提出基于测试矩阵和组合测试相结合的方法,设计场景复杂度评估指标,改进CT算法以在测试效率、条件覆盖和场景复杂度之间取得平衡。

**研究机会:**
- 高维参数空间的高效覆盖策略
- 组合测试与场景复杂度的联合优化
- 约束满足与无效场景过滤
- T-way测试在不同测试强度下的效果评估

### 3. **基于覆盖度量的场景数据库构建** 

提出覆盖度量来定量回答:收集的场景是否覆盖了自动驾驶系统操作设计域的所有相关方面?是否覆盖了驾驶数据中的所有相关方面?实验显示在特定条件下可以达到100%的覆盖率。

**研究机会:**
- 多维度覆盖度量体系的建立
- 场景数据库的完备性评估方法
- 基于覆盖度的场景优先级排序
- 增量式场景数据库构建策略

### 4. **搜索式测试生成与变异测试结合** 

提出基于强变异测试的自动化框架,使用改进的变异模式技术进行变异和基于搜索的测试,采用动态执行方案来引导搜索找到目标变异体。

MutGen方法将变异反馈直接整合到提示设计中,增强LLM生成测试用例的有效性,通过迭代生成过程推动LLM在杀死变异体方面的极限。

Meta的ACH工具是一个变异引导的、基于LLM的测试生成系统,自动生成针对特定故障类型的单元测试,保持可验证的保证以确保测试能够捕获所描述的故障类型。

**研究机会:**
- 变异算子与场景参数的映射关系
- 基于变异分数的场景质量评估
- 搜索算法在变异测试中的优化
- 等价变异体的自动识别与处理

### 5. **强化学习驱动的关键场景生成** 

提出结合强化学习和层次分析法(AHP)的关键测试场景生成新方法,考虑各种潜在影响因素,改进的AHP方法在风险指数与性能指标之间表现出更高的相关性。

通过重要性采样和组合测试方法,基于23个高危险切入事故场景衍生出2052个高危险碰撞前场景,与直接组合相比碰撞率提高2.92倍。

**研究机会:**
- 奖励函数的自动化设计
- 多目标强化学习在场景生成中的应用
- 对抗性场景的在线生成
- 基于强化学习的场景难度自适应调整

## 二、方向

### **方向1: 基于LLM的多约束测试场景生成框架** 

**研究问题:**
- 如何设计有效的提示工程策略以提高LLM生成场景的覆盖度?
- 如何结合形式化约束和自然语言描述指导场景生成?
- 如何评估和保证LLM生成场景的多样性和有效性?

**创新点:**
- 提出多层次提示策略(情境-约束-验证)
- 设计基于覆盖度反馈的迭代生成机制
- 构建场景质量的多维度评估体系

**技术路线:**
1. 分析现有LLM场景生成的局限性
2. 设计层次化的提示工程框架
3. 实现基于RAG的领域知识增强
4. 构建覆盖度引导的迭代优化机制
5. 在自动驾驶仿真平台上验证

### **方向2: 组合测试与场景复杂度联合优化方法** 

**研究问题:**
- 如何在保证高覆盖率的同时生成具有适当复杂度的场景?
- 如何量化场景复杂度并将其作为优化目标?
- 如何处理高维参数空间的组合爆炸问题?

**创新点:**
- 提出场景复杂度的量化模型
- 设计多目标优化的组合测试算法
- 引入约束求解技术处理参数依赖关系

**技术路线:**
1. 建立场景参数化表示模型
2. 设计场景复杂度评估指标体系
3. 开发改进的组合测试算法(如自适应T-way)
4. 实现基于遗传算法的多目标优化
5. 应用于智能驾驶系统测试

### **方向3: 变异引导的高质量场景生成技术** 

**研究问题:**
- 如何设计针对场景参数的有效变异算子?
- 如何利用变异分数指导场景生成和选择?
- 如何自动识别和过滤等价或冗余场景?

**创新点:**
- 提出场景级别的变异算子体系
- 设计变异分数驱动的场景进化策略
- 构建基于语义分析的等价场景识别方法

**技术路线:**
1. 分析场景参数的变异敏感性
2. 设计多层次变异算子(参数级、交互级、场景级)
3. 开发变异分数计算与分析工具
4. 实现基于搜索的变异引导测试生成
5. 在实际系统上评估故障检测能力

### **方向4: 数据驱动与知识引导相结合的场景生成** 

**研究问题:**
- 如何从真实数据中提取高价值场景特征?
- 如何利用领域知识约束数据驱动的生成过程?
- 如何实现场景的增量式生成与数据库更新?

**创新点:**
- 提出混合式场景生成架构
- 设计基于事故数据的关键场景挖掘算法
- 构建知识图谱引导的场景扩展方法

**技术路线:**
1. 收集和分析真实驾驶/事故数据
2. 提取关键场景模式和参数分布
3. 构建领域知识图谱
4. 设计混合生成算法(GAN+规则)
5. 建立场景数据库的覆盖度评估体系

### **方向5: 多目标优化的场景选择与优先级排序** 

**研究问题:**
- 如何在海量候选场景中选择最有价值的测试场景?
- 如何平衡覆盖度、复杂度、真实性等多个目标?
- 如何设计高效的场景优先级排序算法?

**创新点:**
- 提出多维度场景价值评估模型
- 设计基于帕累托最优的场景选择算法
- 引入机器学习预测场景的故障发现能力

**技术路线:**
1. 定义场景价值的多维度指标体系
2. 设计多目标优化算法(NSGA-III等)
3. 训练场景价值预测模型
4. 实现增量式场景选择策略
5. 在大规模场景库上验证效果

## 三、实施建议

### 工具与平台
- **仿真平台:** CARLA, SUMO, Prescan
- **LLM框架:** GPT-4, LLaMA, Claude
- **组合测试工具:** PICT, ACTS, CAGen
- **搜索算法:** EvoSuite, Randoop
- **变异测试:** PIT, MutPy

### 评估指标
- **覆盖度指标:** 参数覆盖率、场景空间覆盖率、边界覆盖率
- **质量指标:** 故障检测率、变异分数、场景真实性
- **效率指标:** 生成时间、场景数量、冗余率

### 创新性建议
1. **跨领域融合:** 将软件测试技术应用到自动驾驶、机器人等领域
2. **理论突破:** 建立场景覆盖度的形式化理论基础
3. **工具开发:** 开发开源的场景生成与评估工具链
4. **实证研究:** 在工业级系统上进行大规模实验验证
